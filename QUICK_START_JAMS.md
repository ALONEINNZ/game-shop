# Quick Start: Mod Jams Feature 🎮

## What is it?
Like itch.io game jams - create private collaborative spaces where teams can upload mods without admin approval. Perfect for competitions, team projects, or private mod collections!

## How to Use

### As a Creator:

1. **Create a Jam:**
   - Go to http://localhost:3007/jams.html
   - Click "Create a Jam"
   - Fill in details (title, description, rules)
   - Submit

2. **Get Your Invite Code:**
   - You'll see an 8-character code (e.g., "ABC12XYZ")
   - Share this code with your team
   - Or share the direct link

3. **Manage Your Jam:**
   - View participants
   - See submissions
   - Edit settings
   - Close when done

### As a Participant:

1. **Join a Jam:**
   - Get invite code from creator
   - Go to http://localhost:3007/jams.html
   - Click "Join with Code"
   - Enter code

2. **Submit Your Mod:**
   - Go to jam page
   - Click "Submit Mod"
   - Upload files and details
   - Instant approval - no waiting!

## Key Benefits

✅ **No Admin Approval** - Submissions go live immediately
✅ **Private & Secure** - Only invited users can access
✅ **Easy Sharing** - Simple 8-character codes
✅ **Full Control** - Creators manage their own space
✅ **Team Friendly** - Collaborate with your team

## Example Use Cases

1. **Mod Competition:**
   - Create jam with theme "Cyberpunk Weapons"
   - Set end date
   - Invite community
   - Vote on best submissions

2. **Team Project:**
   - Private jam for your dev team
   - Upload work-in-progress mods
   - Share feedback internally
   - Release when ready

3. **Game Jam Style:**
   - 48-hour mod creation challenge
   - Theme: "Medieval Magic"
   - Track submissions in real-time
   - Award prizes
