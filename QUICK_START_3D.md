# 🚀 Quick Start - 3D ExusCraft

## Start Server
```bash
cd game-shop
node server.js
```

## Open Browser
```
http://localhost:3007
```

## Hard Refresh
```
Ctrl + Shift + R
```

## What to Expect

### Loading Screen
- 3D rotating cube
- 100 particle ring
- Pulsing glow effects

### Main Page
- **Background:** 1000 floating particles
- **Hero:** Rotating cube (scroll to rotate)
- **Grid Floor:** Neon cyberpunk grid
- **Energy Beams:** 20 connecting lines
- **Holographic Panels:** 10 floating wireframes
- **Portal:** Rotating torus with particles
- **Custom Cursor:** Glowing cursor with trail (desktop only)

### Interactions
- **Hover Cards:** Tilt 15°, lift 30px, shine effect
- **Click Buttons:** 3D ripple effect
- **Open Modals:** 3D rotation entrance
- **Scroll Page:** Parallax 3D movement
- **Move Mouse:** Spotlight follows, cursor trail

## Troubleshooting
- **Not loading?** Hard refresh (Ctrl + Shift + R)
- **Laggy?** Check GPU usage in DevTools
- **Cards not tilting?** Wait 2 seconds for initialization
