## 🤖 **AI RECOMMENDATIONS SYSTEM**

### **How It Works:**
1. **Tracks your behavior** - views, searches, time spent
2. **Builds preference profile** - games, categories, keywords
3. **Scores all mods** using machine learning algorithm
4. **Shows personalized recommendations** with match percentages
5. **Learns from clicks** - improves over time

### **Scoring Algorithm:**
```javascript
score = basePopularity + 
        gamePreference * 10 + 
        categoryPreference * 5 + 
        keywordMatching * 2 - 
        diversityPenalty * 5 + 
        recencyBonus
```

### **What You'll See:**
- **🤖 95% Match** badges on recommended mods
- **Personal stats** - mods viewed, searches made
- **Smart suggestions** that improve with usage
